# Министерство юстиции Российской Федерации

Этот проект представляет собой полноценного Discord-бота для деятельности реального министерства в рамках ролеплей-сервера. Он разработан в духе ведомственной структуры Минюста РФ и включает административный, служебный и статистический функционал, необходимый для полноценной работы органов юстиции в Discord.

## Что умеет бот

- выдача, снятие и корректировка баллов сотрудников;
- просмотр баланса каждого участника;
- назначение и снятие классных чинов;
- назначение и снятие должностей;
- служебная карточка сотрудника;
- конфигурация параметров ведомства;
- приветствие новых участников;
- ведение служебных логов в канале журнала;
- сводный статус ведомства;
- поддержка реальной структуры Минюста РФ: чины, должности, регламенты, служебная логика.

## Установка

1. Установите зависимости:
   npm install
2. Создайте файл `.env` по образцу `.env.example` и заполните параметры:
   DISCORD_TOKEN=...
   CLIENT_ID=...
   GUILD_ID=...
3. Зарегистрируйте команды Discord:
   npm run register
4. Запустите бота:
   npm start

## Основные команды

- /minjust-help — помощь по системе
- /minjust-profile [user] — служебная карточка сотрудника
- /minjust-status — сводка по ведомству
- /minjust-balance show [user] — проверка баланса
- /minjust-balance add user amount reason — выдача баллов
- /minjust-balance remove user amount reason — снятие баллов
- /minjust-balance set user amount reason — точная установка баланса
- /minjust-rank list — список классных чинов
- /minjust-rank assign user rank — назначение чина
- /minjust-rank clear user — снятие чина
- /minjust-position list — список должностей
- /minjust-position assign user position — назначение должности
- /minjust-position clear user — снятие должности
- /minjust-config view — просмотр настроек ведомства
- /minjust-config set key value — изменение настроек

## Настройки ведомства

Бот поддерживает изменение следующих параметров:

- name
- city
- currency
- color
- welcome-message
- welcome-channel
- log-channel
- admin-role
- footer-text

## Структура данных

Данные сохраняются в директории `data/`:

- `data/guilds/<guildId>.json` — служебные настройки сервера, чины, должности;
- `data/balances/<guildId>.json` — балансы участников.

## Дополнительные возможности

- автоматическое приветствие новых участников;
- создание служебных ролей по чинам и должностям;
- служебная аудитория в логе;
- поддержка базового административного доступа через права сервера или роль администратора.

## Примечание

Этот проект реализован в максимально реалистичном формате для ведомственной ролевой игры и может быть расширён под полную структуру Минюста: отделы, департаменты, приказы, комиссии, реестры и централизованная служебная база.

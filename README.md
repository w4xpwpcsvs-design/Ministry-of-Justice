# Министерство юстиции Российской Федерации

Этот проект представляет собой полноценного Discord-бота для деятельности реального министерства в рамках ролеплей-сервера. Бот обеспечивает служебную структуру, балансовую систему, кадровое управление и справочный интерфейс, соответствующий логике министерства.

## Главные возможности

- выдача, снятие и корректировка баллов сотрудников;
- просмотр баланса каждого участника;
- назначение и снятие классных чинов;
- назначение и снятие должностей;
- служебная карточка сотрудника;
- структура ведомства с основными подразделениями;
- справка по структуре и командам;
- конфигурация параметров ведомства;
- приветствие новых участников;
- ведение служебных логов в канале журнала;
- сводный статус ведомства;

## Команды

- /minjust-help — краткая справка по структуре и рабочим командам
- /minjust-structure — структура ведомства и основные подразделения
- /minjust-profile [user] — служебная карточка сотрудника
- /minjust-status — сводка по ведомству
- /minjust-balance show [user] — проверка баланса
- /minjust-balance add user amount reason — выдача баллов
- /minjust-balance remove user amount reason — снятие баллов
- /minjust-balance set user amount reason — точная установка баланса
- /minjust-rank list — список классных чинов
- /minjust-rank assign user rank — назначение чина
- /minjust-rank clear user — снятие чина
- /minjust-position list — список должностей
- /minjust-position assign user position — назначение должности
- /minjust-position clear user — снятие должности
- /minjust-config view — просмотр настроек ведомства
- /minjust-config set key value — изменение настроек

## Установка

1. Установите зависимости:
   npm install
2. Создайте файл `.env` по образцу `.env.example` и заполните параметры:
   DISCORD_TOKEN=...
   CLIENT_ID=...
   GUILD_ID=...
3. Зарегистрируйте команды Discord:
   npm run register
4. Запустите бота:
   npm start

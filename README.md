# Министерство юстиции Российской Федерации

Этот проект содержит Discord-бота для ролевого сервера в духе реального Министерства юстиции Российской Федерации. В боте реализованы:

- система баллов/поощрений: выдача, снятие, установка и проверка баланса;
- управление классными чинами и должностными позициями;
- настройка текстов, цвета, канала логов, роли администратора и приветственного сообщения;
- приветствие новых участников;
- справка и команды для администраторов.

## Установка

1. Установите зависимости:
   npm install
2. Скопируйте .env.example в .env и заполните значения:
   cp .env.example .env
3. Создайте бота в Discord Developer Portal и получите токен.
4. Зарегистрируйте команды:
   npm run register
5. Запустите бота:
   npm start

## Переменные окружения

- DISCORD_TOKEN — токен Discord бота
- CLIENT_ID — ID клиента бота
- GUILD_ID — ID основного сервера (если нужно регистрировать команды только там)

## Команды

### /minjust-help
Показывает справку.

### /minjust-balance show [user]
Показывает баланс баллов участника.

### /minjust-balance add user amount reason
Выдаёт баллы участнику.

### /minjust-balance remove user amount reason
Снимает баллы у участника.

### /minjust-balance set user amount reason
Устанавливает точное количество баллов участника.

### /minjust-rank list
Показывает список классных чинов.

### /minjust-rank assign user rank
Назначает классный чин участнику и создаёт/подключает соответствующую роль.

### /minjust-rank clear user
Снимает чин с участника.

### /minjust-position list
Показывает список должностей.

### /minjust-position assign user position
Назначает должность участнику и создаёт/подключает соответствующую роль.

### /minjust-position clear user
Снимает должность с участника.

### /minjust-config view
Показывает текущие настройки сервера.

### /minjust-config set key value
Изменяет настройки сервера, например:
- name
- city
- currency
- color
- welcome-message
- welcome-channel
- log-channel
- admin-role
- footer-text

## Структура данных

Бот сохраняет данные в директории `data/`:

- `data/guilds/<guildId>.json` — настройки сервера, чины и должности участника;
- `data/balances/<guildId>.json` — балансы участников.

## Примечание

Бот выполнен в стиле официального министерства, но не является официальной системой государственного ведомства. Его можно адаптировать под любой RP-сервер и расширять по мере развития роли.
